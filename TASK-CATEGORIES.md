## Executive summary (read this first)

Track 2 has four card families (F1–F4), organized around the **role of the text corpus**
in each forecasting task. F1 tests incremental text signal on a seen series. F2 tests
early text signals of a regime change. F3 tests cross-asset inference from text about one
market to correlated markets. F4 tests whether text foreshadows a shock that drives
extreme tail outcomes.

The full guide is at `docs/CATEGORIES.md`. Go there for the complete description of each
family, including: what it tests, the role of text, which score component is stressed,
as-of date and text-cutoff rules, an example card, and common mistakes.
